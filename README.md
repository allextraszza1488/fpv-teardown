# Inside a 5-inch FPV quad

An explorable 3D teardown of a 5-inch FPV quad: real wiring (battery leads,
motor phases, DShot, CRSF, video), a throttle slider with live rpm / current /
power, and dives into the flight controller, ESC, motor and battery.

**Open it:** https://allextraszza1488.github.io/fpv-teardown/

Built with 3Disle. This repo holds only the built page. Current and rpm
figures are estimates for a 6S quad on 2207 1750 KV motors (approx.).
